## 🛠️ 安装部署

### 方式一：标准安装（推荐新手）

#### 1. 环境准备

```bash
# 检查Python版本（需要3.9+）
python --version

# 如果没有Python，请先安装：
# Windows: https://python.org/downloads/
# macOS: brew install python3
# Ubuntu: sudo apt install python3 python3-pip
```

#### 2. 创建虚拟环境

```bash
# 创建项目目录
mkdir heuristic-platform && cd heuristic-platform

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
```

#### 3. 安装依赖

```bash
# 下载requirements.txt到项目目录
# 然后安装依赖
pip install -r requirements.txt

# 如果安装遇到问题，可以尝试：
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

#### 4. 启动服务

```bash
# 启动平台
python app.py

# 看到以下信息表示启动成功：
# 🚀 服务已启动：http://127.0.0.1:5000
# 安全配置: {'max_file_size_mb': 100, ...}
```

### 方式二：Docker部署（推荐生产环境）

```bash
# 1. 构建Docker镜像
docker build -t heuristic-platform .

# 2. 运行容器
docker run -d \
  --name heuristic-platform \
  -p 5000:5000 \
  -v $(pwd)/config.json:/app/config.json \
  -v $(pwd)/uploads:/app/uploads \
  heuristic-platform

# 3. 访问平台
# 浏览器打开: http://localhost:5000
```

### 方式三：开发环境部署


### 3. ⚡ 启发式算法引擎

#### 关联规则挖掘

**🧠 启发式优化**
- **剪枝策略**: 智能剪枝减少搜索空间
- **增量更新**: 支持数据增量更新
- **并行计算**: 多线程并行处理
- **内存优化**: LRU缓存管理

**⚙️ 参数配置**
```json
{
    "algorithm": {
        "min_support": 0.05,      // 最小支持度
        "min_confidence": 0.4,    // 最小置信度
        "min_lift": 1.0,          // 最小提升度
        "max_len": 5,             // 最大项集长度
        "enable_pruning": true,    // 启用启发式剪枝
        "enable_parallel": false   // 并行计算（开发中）
    }
}
```

- **Chi-Square检验**: 分类变量关联性检验
- **KS检验**: 分布一致性检验

**🔧 高级特性**

```
  最小支持度: 0.05-0.08
```
